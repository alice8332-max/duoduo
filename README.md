# 多多

本地优先的个人资产盘点工具。数据只保存在浏览器 `localStorage`，不上传服务器。

## 在线使用

https://alice8332-max.github.io/duoduo/

## 功能

- 总览：总资产、净资产、投资比例、资产配置、黄金定投、本月消耗、提醒
- 盘点：按上次快照和期间流水计算应有市值，差额归因为消费 / 投资盈亏 / 未解释
- 账户：自定义账户树、积存金克数、定存、信用卡负债
- 资产配置：自定义分组，支持总资产 / 投资资产两种份额口径
- 导入：只读投资平台 `invPlatformData_v1` 的场内持仓
- 数据安全：自动备份、手动备份、JSON 导入导出

## 开发

- 工作副本：`多多.html`
- 部署副本：`index.html`
- 两者必须 SHA256 一致
- 发布前运行 JS 语法检查和自检
